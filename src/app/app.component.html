HTTP Request Cache — проверка сценариев

HTTP-запросы перехватываются фейковым перехватчиком (FakeApiInterceptor), сети нет. Каждый реальный вызов метода у HttpClient увеличивает счётчик и логируется. Ответ приходит с задержкой ~0.5с, общее для всех. Смотрите лог и счётчики.
